# App.tsx

## Summary

This source contains a React Native application (App.tsx) that implements a watercolor-style biometric data visualization system called "Sato." The app renders health metrics as artistic watercolor graphics using @shopify/react-native-skia, with a layered approach including atmosphere, body, accent, and ground layers. It features three predefined health profiles (balanced, spike, calm) with distinct color palettes, each displaying metrics for time in range, variability, activity, consistency, and feeling through a central "state bloom" visualization.

The application uses deterministic pseudo-random generation via a seeded hash function to create consistent visual elements like stains, speckles, and petal shapes for the watercolor effect. Biometric data (sleep, meals, runs, glucose, stress, notes) is processed through a featuresFromBiometric function and transformed into VisualTokens for rendering. The interface includes haptic feedback via expo-haptics for user interactions and presents a mobile-first design with segmented controls for profile switching.
