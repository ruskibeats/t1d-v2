# sceneBuilder.ts

## Summary

This TypeScript source file implements a scene builder for a visualization system that transforms artifact features into layered visual scenes. The code defines a `buildRenderScene` function that processes a list of `ArtifactFeatures` and generates a structured `RenderScene` composed of atmosphere, body, accents, and ground visual elements.

## Key Takeaways

- The system maps artifact categories (sleep, run, meal, glucose, stress) to domain types (rest, move, nourish, energy, ground) for visual styling
