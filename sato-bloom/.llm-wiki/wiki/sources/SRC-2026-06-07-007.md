# UBIQUITOUS_LANGUAGE.md

## Summary

This document defines the ubiquitous language for T1D Companion v2, establishing a shared vocabulary across teams working on a Type 1 Diabetes management application. The system centers on the "State Bloom" - a visual representation that transforms five health dimensions (Time in Range, Variability, Activity, Consistency, and Feeling) into a watercolor cloud visualization rendered via Skia, with each dimension mapping to a colored pigment layer that forms translucent petals around a central core.

The language spans multiple domains: the State Bloom visual system with its profiles (Balanced, Spike, Calm) for metabolic archetypes; the meal/forecast pipeline including parsed foods, food candidates, meal totals, and forecast results; safety mechanisms like the Safety Scaffold that prevents harmful outputs; and UI concepts including Cards and Intents that structure user interactions. Historical context from similar meals informs predictions, and all outputs pass through safety validation before reaching users.

## Key Takeaways

- ["State Bloom is a Skia-based watercolor visualization system that transforms five health dimensions into a blooming cloud with translucent pigments"] ["The State Bloom has three metabolic profiles: Balanced (green), Spike (blue), and Calm (orange) that configure color palettes and default metrics"] ["The meal pipeline transforms user text into parsed foods, finds food candidates, computes food evidence, and aggregates into meal totals"] ["A 3-compartment physiology model generates forecast results with uncertainty bands based on carb estimation"] ["The Safety Scaffold acts as a final veto gate, blocking banned words and dosing patterns before outputs reach users"] ["Legacy terminology like 'Orb' and 'Sim user' have been deprecated in favor of 'Bloom Card' and 'Legend' respectively"]
