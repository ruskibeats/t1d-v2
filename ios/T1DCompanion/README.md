# T1DCompanion SwiftUI Prototype

This directory contains a native SwiftUI prototype/reference implementation for T1D Companion mobile screens.

## Status

Reference/prototype only. The production mobile app of record is planned for:

```text
/root/tld-v2/mobile/
```

using Expo + React Native + TypeScript.

## Use this prototype for

- understanding early screen concepts
- referencing interaction ideas
- comparing native iOS polish
- exploring future Swift native-module UX when needed

## Do not use this prototype for

- new production product features
- parallel implementation of the React Native app
- source-of-truth mobile routing/state decisions

Production mobile decisions are captured in:

- `docs/adr/ADR-001-mobile-react-native-expo-card-contract.md`
- `docs/mobile-showcase-runner-strategy.md`
- `DESIGN.md`
