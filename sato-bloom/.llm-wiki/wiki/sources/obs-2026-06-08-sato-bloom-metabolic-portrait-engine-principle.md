# 🔴 Observation: Sato Bloom Metabolic Portrait Engine principle
User crystallized the canonical Sato Bloom design principle: the reference image is material direction, not interaction direction. Borrow watercolor softness, pigment behavior, palette balance, premium whitespace, editorial typography, Japanese restraint, scale, and warm ivory paper. Do not borrow flower-chart information architecture. Bloom is a living watercolor portrait generated by the body's rhythm; the clock exists mathematically but is invisible by default. User first sees art, then touch reveals hidden temporal structure. Internally renamed BloomClock to MetabolicPortraitEngine while preserving BloomClock compatibility export.
