# normalize.ts

## Summary

This TypeScript source file defines normalization functions for converting biometric and other data into standardized artifact features. The `normalizeFeatures` function takes partial `ArtifactFeatures` data and constrains each property to specific valid ranges using a clamp helper function - intensity, duration, volatility, and recovery values are clamped to 0-1 (or 0.1-1 in some contexts), while balance is clamped to -1 to 1. The `featuresFromBiometric` function transforms raw biometric inputs into normalized features based on the event category, with specific calculation formulas for meal, run, sleep, glucose, and stress categories.

## Key Takeaways

- The clamp function constrains values to specified minimum and maximum bounds using Math.max and Math.min
- normalizeFeatures ensures all artifact features fall within predefined valid ranges with default fallback values
- Meal features are calculated from carbs, protein, and fat with intensity based on total macros and balance reflecting protein-to-carb ratio
- Run features derive intensity and duration from activity minutes, while sleep features use sleep score to determine multiple attribute values
- Glucose and stress categories map their respective metrics to intensity, volatility, and recovery scores with stress having a negative balance
