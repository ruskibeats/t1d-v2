# Sparky-Bloom four-layer architecture synthesized
Synthesized the Sparky-Bloom architecture: four integrated layers — SparkyFitnessServer (Node.js/Express/PostgreSQL backend), SparkyFitnessMobile (Expo RN base), T1D Companion AI (Python FastAPI sidecar for meal impact forecasting + pattern detection), and Sato Bloom (Skia watercolor pigment system + BloomClock visualization). The Bloom pigment system (11 metabolic pigments from pigmetSystem.ts) already maps to metabolic states (slowCarb, fastSugar, fatDelay, proteinSteady, movement, recovery, stress, sleepDebt, settling, baseline) that align perfectly with T1D's meal impact categories. Wrote a full PRD at issues/prd.md covering 20 user stories, module architecture, schema changes, API contracts, and testing decisions.
