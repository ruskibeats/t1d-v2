# Sato watercolor visualization system
Sato transforms T1D health metrics into a watercolor State Bloom using React Native Skia. The system uses a five-layer architecture (atmosphere, body, accents, ground, texture) where each of the five health dimensions (time in range, variability, activity, consistency, feeling) produces a Pigment - a colored, semi-transparent layer rendered as clusters of oval petals. The pigments overlap in a Core region where they blend into a unified metabolic state visualization. Three profile personas (Balanced, Spike, Calm) configure distinct color palettes and metric baselines, with haptic feedback on the pressable Bloom Card.
