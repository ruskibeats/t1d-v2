# Pattern Genome

User-specific metabolic traits derived from 90-day meal history, forming a personalized diabetes pattern map

## Definition

A Pattern Genome generates personalized metabolic traits for each user — such as breakfast spike tendency, high-fat delay tendency, exercise sensitivity, overnight risk, variability profile, and repeat trigger foods — from their meal history and graph-derived context.

## Purpose

Turns T1D Companion from a one-off meal forecast tool into a personalized metabolic map. Users learn how specific foods behave for them individually, rather than just asking "what happens if I eat X?"

## Traits

- Breakfast spike tendency
- High-fat delay tendency  
- Exercise sensitivity
- Overnight risk
- Variability profile
- Repeat trigger foods
