# README.md

## Summary

T1D Companion v2 is an educational meal-impact companion and glucose forecast simulator designed for Type 1 Diabetes management. The application takes natural language meal descriptions, parses foods, looks up nutrition data from Postgres or OpenFoodFacts, estimates carbohydrate totals with uncertainty, and runs physiology-inspired glucose forecasts using one of 12 simulated T1D profile anchors.

## Key Takeaways

- ["Educational tool only - explicitly not medical advice and does not recommend insulin dosing"]
["Supports 12 simulated T1D profile anchors for personalized glucose forecasting"]
["Integrates with Postgres/OpenFoodFacts for nutrition data with deterministic fallback foods"]
["Includes safety veto gate to prevent emergency/dosing/treatment language in output"]
["Focuses on text-first UX prototype for eventual mobile app deployment"]
["Uses physiology-inspired compartment model for glucose forecasts"]
["Provides historical context from similar meals when available"]
