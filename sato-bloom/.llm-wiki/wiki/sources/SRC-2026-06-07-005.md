# mapper.ts

## Summary

This TypeScript module (`mapper.ts`) provides a mapping system that converts artifact features into visual tokens for rendering data-driven visualizations. The core functionality centers around the `featuresToTokens` function, which takes an `ArtifactFeatures` object and produces `VisualTokens` that define graphical properties like ellipse count, spread, blur, noise, and color palette.

## Key Takeaways

- The module defines color palettes for six categories: meal, run, sleep, glucose, stress, and note
