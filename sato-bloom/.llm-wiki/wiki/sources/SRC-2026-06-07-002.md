# artifact.ts

## Summary

This source defines a comprehensive type system for a health and wellness visualization application. It establishes enums for event categories (meal, run, sleep, glucose, stress, note), domains (rest, move, nourish, energy, ground), and z-bands (atmosphere, body, accent, ground) that organize different types of health data. The ArtifactFeatures interface captures quantitative metrics like intensity, duration, balance, volatility, recovery, and seed values for events, while VisualTokens provides styling parameters such as palette, ellipse count, blur, noise, and opacity settings.

## Key Takeaways

- EventCategory defines six health-related event types for tracking wellness activities
Domain provides five categorical groupings (rest, move, nourish, energy, ground) for organizing visual elements
ZBand establishes four vertical layer bands (atmosphere, body, accent, ground) for scene composition
ArtifactFeatures captures event metadata including intensity, duration, balance, volatility, and recovery metrics on 0..1 or -1..1 scales
VisualTokens contains styling and layout parameters (palette, blur, noise, opacity, spread coordinates) for rendering
VisualToken represents individual renderable elements with position, dimensions, color, rotation, and optional blend mode/noise
RenderScene aggregates VisualTokens into atmosphere, body, accents, and ground layer arrays
